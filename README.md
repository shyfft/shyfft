# Shyfft

Build a modern, mobile-first social media web app named shyfft, inspired by Instagram.



Design:



- Premium green-to-blue gradient theme.

- Dark mode and light mode toggle.

- Clean, smooth, responsive mobile UI.

- Custom shyfft logo and bottom navigation.



Pages:



- Home feed with posts.

- Explore and search.

- Create photo/video posts and Reels.

- 24-hour Stories.

- User profiles and username selection.

- Likes, comments, saves, follow/unfollow.

- Direct messaging and notifications.

- Settings, privacy, block and report features.



Use React, Tailwind CSS and a scalable component structure. Make all navigation buttons functional. Prepare the app for Supabase authentication, PostgreSQL database, media storage and real-time messaging.



Start with the complete responsive UI. Do not use Instagram's exact logo or branding.
